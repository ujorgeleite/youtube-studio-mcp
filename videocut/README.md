# VideoCut

Montagem por conteúdo, 100% local: descobre as histórias que existem nos seus
takes, mostra as evidências e gera uma primeira montagem para continuar no
Filmora.

```bash
cd videocut
make install
make test
```

Requisitos: macOS com Apple Silicon, Python 3.12+, `ffmpeg`/`ffprobe` no PATH.

Veja `CONTEXT.md` para arquitetura e limites, e `PLANO.md` para o andamento.
